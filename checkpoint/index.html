FEATURED PROJECT

Issue Tracker API

A REST API built to manage software issues, track progress, and organize development tasks.

The Problem

Software development teams need a way to organize bugs, track issues, and manage their progress. This project addresses that need by providing an API for managing software issues and related information.

My Role

I worked on developing the backend API, creating routes and controllers, connecting the application to MongoDB, and adding validation and error handling. I also tested the endpoints to make sure they worked correctly.

What I Built

Using TypeScript, Node.js, Express, MongoDB, and Zod, I developed API functionality for creating, viewing, updating, and deleting issues.

I also implemented issue classification, status updates, assignments, comments, test cases, searching, filtering, sorting, and pagination.

What I'd Improve

In the future, I would like to add a more user-friendly frontend interface so users can manage issues without needing to send API requests manually. I would also like to continue improving authentication and the overall user experience.
